# Build & run

Borma's Xcode project is generated by [`xcodegen`](https://github.com/yonaskolb/XcodeGen) from `project.yml`. The generated `Borma.xcodeproj/` is gitignored — never committed. This keeps Xcode's randomly-ordered `project.pbxproj` out of diffs and merge conflicts.

## First-time setup

```bash
brew install xcodegen     # if not installed
xcodegen generate         # writes Borma.xcodeproj from project.yml
open Borma.xcodeproj      # then set your dev team in Signing & Capabilities
```

In Xcode: **Borma target → Signing & Capabilities → Team**, pick your own team. `CODE_SIGN_STYLE = Automatic` is already configured, so Xcode handles the certificate and provisioning profile.

⌘R to build and run.

## Signing & entitlements

`project.yml` wires three signing-related settings: `CODE_SIGN_STYLE = Automatic`, `ENABLE_HARDENED_RUNTIME = YES`, and `CODE_SIGN_ENTITLEMENTS = Borma.entitlements`. The entitlements file is tiny — it enables `com.apple.security.app-sandbox` only. Add new capabilities (e.g. a security-scoped bookmark or network access) by editing `Borma.entitlements` directly; it's referenced by path from `project.yml`, so no `xcodegen generate` is needed for entitlement-only changes (regenerate only if you change the `CODE_SIGN_ENTITLEMENTS` wiring itself).

## Regenerating after project changes

Whenever `project.yml` changes (new source folder, new dependency, build setting change), regenerate:

```bash
xcodegen generate
```

Xcode picks up the regenerated project automatically.

## Never edit Borma.xcodeproj by hand

`Borma.xcodeproj/project.pbxproj` is a build artifact. Direct edits are wiped on the next `xcodegen generate`. To change a build setting, source folder, or dependency, edit `project.yml` and regenerate.

## CLI builds (optional)

```bash
xcodebuild -project Borma.xcodeproj -scheme Borma -configuration Debug build
```

For ad-hoc unsigned testing builds (useful in CI-like contexts), pass:

```bash
CODE_SIGN_IDENTITY="" CODE_SIGNING_REQUIRED=NO CODE_SIGNING_ALLOWED=NO
```

## Dependencies

Single SPM package: `KeyboardShortcuts` (Sindre Sorhus). Pinned via `project.yml`'s `packages:` section. SPM resolves on first Xcode open; `Package.resolved` lives inside `Borma.xcodeproj/` and isn't committed.
